# anime sliding puzzle

built a 3x3 sliding puzzle game using attack on titan art because i wanted to make smth interactive with anime. plus, i wanted to practice working with arrays adn css background positioning.

## features 
-- 3x3 grid: classing sliding puzzle mechanics. slide the tiles to fix the image. (i originally made it 4x4 but it was too hard so i switched to 3x3 lol)
--timer&moves: keeps track of how fast you are and how many moves u take.
--confetti with screen: when u win, a canvas explosion of confetti goes off. no libraries used.
--glassmorphism ui. the whole interface uses backdrop-filter and semi-transparent backgrounds.

# how to run

just open index.html in ur browser
